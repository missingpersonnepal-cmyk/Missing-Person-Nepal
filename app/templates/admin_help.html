What the system does

English

  • Collects public reports and direct submissions for disaster-related missing persons.
  • Keeps source links, notes, and evidence attached to the right person record.
  • Helps admins spot likely duplicates before publishing or merging cases.
  • Supports search, review, publishing, export, and shift handover in one place.
यस प्रणालीले के गर्छ

नेपाली

  • विपदासँग सम्बन्धित बेपत्ता व्यक्तिका सार्वजनिक रिपोर्ट र प्रत्यक्ष निवेदनहरू संकलन गर्छ।
  • स्रोत लिंक, नोट, र प्रमाण सही व्यक्तिको रेकर्डसँग सुरक्षित राख्छ।
  • प्रकाशन वा मर्ज गर्नु अघि सम्भावित दोहोरो रेकर्ड पत्ता लगाउन सहयोग गर्छ।
  • खोज, समीक्षा, प्रकाशन, export, र shift handover एउटै ठाउँमा समर्थन गर्छ।
Workflow

How to use it

  1. Create or select an event first.
  2. Open Discovery and review candidate public sources.
  3. Move relevant items into submissions and check duplicates.
  4. Approve a new case or attach the source to an existing person.
  5. Publish the case, keep it updated, and export handover files when needed.
कार्यप्रवाह

कसरी प्रयोग गर्ने

  1. पहिले event छान्नुहोस् वा नयाँ event बनाउनुहोस्।
  2. Discovery खोलेर candidate सार्वजनिक स्रोतहरू समीक्षा गर्नुहोस्।
  3. सम्बन्धित विवरण submissions मा सारेपछि duplicate जाँच गर्नुहोस्।
  4. नयाँ case approve गर्नुहोस् वा स्रोतलाई existing व्यक्तिसँग जोड्नुहोस्।
  5. case publish गरेर update राख्नुहोस्, र आवश्यक परे handover file export गर्नुहोस्।
Admin tips

Good practice

  • Verify phone numbers, names, and locations before publishing.
  • Keep one source URL attached only once per person.
  • Use the shift checklist before handing over to the next admin.
  • When in doubt, save the evidence first and decide with a human review.
व्यावहारिक सुझाव

राम्रो अभ्यास

  • प्रकाशन अघि फोन नम्बर, नाम, र स्थान जाँच गर्नुहोस्।
  • एउटै स्रोत URL एउटै व्यक्तिमा एक पटक मात्र जोड्नुहोस्।
  • अर्को admin लाई बुझाउन shift checklist प्रयोग गर्नुहोस्।
  • दुविधा भएमा पहिले प्रमाण सुरक्षित राख्नुहोस् र मानव समीक्षा गर्नुहोस्।
